How to play

  1. Search for a song in the catalogue and submit it as a guess.
  2. Compare its properties with the mystery song.
  3. Use the arrows to work out whether the answer has more streams, a longer duration, or a later release year.
  4. Keep guessing for as long as it takes. There is no guess limit.
